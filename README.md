# Lodestar Build Planner

A fan-made, single-page build planner for Starfield. Open `index.html` in a browser, or serve it with GitHub Pages.

- Pick one of 20 backgrounds (three starting skills) and up to three traits, with the exclusive pairs enforced.
- Plan one skill point per level, from level 2 up to level 150.
- Tier gates are checked for you: Advanced needs 4 points in that tree, Expert 8, Master 12.
- Every rank shows the challenge you need to finish first, and the snapshot lists the next challenges to chase.
- Six sample builds, undo, a build code to copy and load, and a searchable index of all 82 skills.
- Original icons for every skill. No game art is used.

Your plan is saved in your browser only. Copy the build code to keep it elsewhere.

Data is compiled from community guides and may drift with game updates. Not affiliated with Bethesda.
